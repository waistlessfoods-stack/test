# WaistLess Foods Events, Email, and Ongoing Support Proposal

Prepared: August 17, 2026  
Prepared for: Amber and John  
Status: Proposal for review; no Events implementation has begun

## Project Context

The original WaistLess Foods website proposal was intentionally affordable and positioned as both a birthday gift and a foundation for growth. The original package was priced at **$700**, with the overall website investment to date understood to be approximately **$1,000**. It described a broad CMS-driven website containing recipes, services, bookings, e-commerce foundations, newsletter signup, and a basic Events and Classes calendar.

The website has since grown into a much larger custom platform with Contentful editing, authentication, payments, service pages, recipes, bookings, reviews, email functionality, and administrative tools. The goal of this proposal is not to charge for the whole platform again. It defines only the additional work needed to turn the earlier basic Events idea into a clear, reusable Events section that Amber can manage.

Because the original proposal already mentioned Events and newsletter foundations, the following prices are reduced relationship-based add-on prices. They assume the current website architecture can be reused and the scope remains intentionally small.

### Original business goal

The original strategy was to move WaistLess Foods from an Instagram-first presence into a centralized digital home where visitors can discover Chef Amber's recipes, services, events, and healthy, eco-conscious approach. It identified manual event promotion and booking inquiries as barriers to growth and positioned Contentful as the tool that would let Amber manage evolving content.

The small Events MVP continues that original goal. It gives public cooking classes and other events a permanent, searchable home on the WaistLess Foods website while retaining the approachable, Houston-based positioning described in the original plan. Its purpose is to help visitors move from discovering Chef Amber to taking an action—cook, book, or join—without turning this phase into a custom ticketing platform.

## Option A — Small Events MVP

The Events MVP will give visitors one place to discover upcoming WaistLess Foods events while keeping registration outside the website for the first version.

### Included

- Add an **Events** tab to the desktop and mobile navigation.
- Build one Events listing page.
- Build one reusable event-detail page template.
- Add a simple Contentful Events content type.
- Allow Amber to edit the event title, short summary, description, date, time, location, featured image, optional video link, and external registration URL.
- Add a clear **Register** button on each event page.
- Display a simple upcoming or past event state based on the event date.
- Check the Events pages on desktop, tablet, and mobile.
- Add and verify one initial event using final content supplied by Amber.
- Include one consolidated revision round.

### Registration approach

Version one will use **external registration**. Eventbrite is the recommended starting point, although another agreed registration link can be used. Amber will manage the registration record in that service and add its URL to the matching Contentful event.

The WaistLess Foods website will market the event. The external provider will handle registration, tickets, payment, capacity, waitlists, reminders, cancellations, and attendee records where those features are needed. This keeps the website addition small and prevents those systems from being rebuilt before the business knows which features it regularly uses.

### Not included

- Registration forms stored directly on the WaistLess Foods website.
- Custom ticket checkout or Stripe event payments.
- Website-managed capacity, waitlists, reminders, cancellations, refunds, or attendee administration.
- Ticket tiers, discount codes, assigned seating, check-in tools, or calendar synchronization.
- Custom video hosting, photography, videography, or event copywriting.
- Multiple custom event layouts or a separate event administration dashboard.

Any of these can be quoted later if real event activity shows that bringing registration onto the website would provide enough value.

## Option B — Basic WaistLess-Managed Newsletter Workflow

The current website already includes newsletter signup, a branded welcome email, duplicate protection, and unsubscribe handling. This optional add-on would create a small internal workflow for preparing and sending a standard WaistLess Foods newsletter without attempting to recreate a full Mailchimp-style marketing platform.

“WaistLess-managed” means the content and audience workflow belongs to WaistLess Foods. A professional email-delivery provider will still send the messages; the website will not operate its own mail server.

### Included

- One reusable branded newsletter layout based on the current welcome-email design.
- Editable subject, preview text, headline, body, image, and call-to-action link.
- A protected way to prepare the newsletter content.
- A test-send step before release.
- Sending to active WaistLess Foods newsletter subscribers through the selected provider.
- Existing unsubscribe and duplicate protections.
- Basic success and failure logging.
- One initial newsletter setup and one revision round.

### Not included

- Advanced segmentation, multi-step automations, visual drag-and-drop editing, or detailed campaign analytics.
- Unlimited newsletter design or copywriting.
- Subscriber migration from an unspecified external platform.
- Guaranteed inbox placement or third-party sending costs.

**Relationship-based fixed price: USD $400**

The final workflow depends on access to the approved sending account and confirmation of who is allowed to prepare and send campaigns.

## Option D — Small Monthly Retainer

If Amber and John expect continued website, Contentful, Events, and email requests, a small retainer can replace repeated individual quotes.

### Included capacity

- One scheduled monthly planning and progress meeting of up to 30 minutes.
- A short written update covering completed work and the next priority.

- The monthly meeting counts toward the reserved capacity.

- Third-party subscriptions, transaction fees, advertising, content production, and emergency support are not included.
- The retainer begins after the current website punch list is closed or the remaining original work is documented separately.
